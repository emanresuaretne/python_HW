# Задача. Электронный дневник
Напишите функцию performance, 
которая будет принимать три именнованных аргумента
- строку - название входного файла
- строку - название выходного файла
- целое число или число с плавающей точкой - порог аттестации 

Стандартные значения аргументов: input.txt, output.txt, 2

Функция должна 
прочитывать файл с оценками учеников 
по различным предметам за отчётный период 
и компоновать файл с отчётом по успеваемости. 
В случае, если ученик не получил оценок за предмет, 
или средний балл оказался ниже порогового, 
функция должна отмечать неаттестацию, 
иначе выводить средний балл с округлением до десятых
